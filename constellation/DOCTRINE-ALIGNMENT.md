# Doctrine alignment

Source: [The Syntarion Doctrine of Being](https://docs.google.com/document/d/1DHM9Sn9W7yUIq5v_co_jeE0Yu-7tYaHy/edit), fetched from the connected Google Drive document on October 22, 2026. Source file: `The Syntarion Doctrine of Being.docx`, last modified March 4, 2026.

The page uses only the English labels and plain-English paraphrases in `doctrine.js`. The document's invented-language terms are deliberately omitted.

## Applied structure

- Pillars of Being: Spirit, Soul, Body, Mind. These describe what is given.
- Instruments of Expression: Affect, Will, Whim, Dream. These describe how being is expressed in the world.
- Navigator ordering follows these two groups. Original class-to-attribute mappings remain intact; source chart array ordering in `data.js` is intentionally unchanged.
- Discipline is separate from pillar/instrument membership. Class colors, the Psynth-only Praethacy rule, and the reveal behavior are preserved.
- Psynth is shown in a separate revealed-class section. Praetor is a title, not a ninth pillar or instrument. The doctrine gives no Psynth-to-aspect assignment; per the user (October 28), Psynth's aspect is Hope, kept outside the eight-aspect table.
- Selected class descriptions explain their aspect in English instead of inventing a discipline-specific metaphysical claim.
- Generic ability descriptions say effects remain undefined. The user is supplying class abilities. Existing imported Syntarion ability descriptions are preserved as archive content, not presented as rules derived from this doctrine.

## Source ambiguity and mechanical boundary

The creed uses the word Essence, while the formal Pillars table names Mind. This UI follows the formal table, preserves Mind, and does not introduce Essence as a fifth pillar or silently equate the two.

The doctrine provides no numerical AP costs, prerequisites, spell effects, or class advancement rules. The existing sandbox costs and prerequisites are unchanged and remain explicitly provisional in the README. Being/expression groups do not gate purchases, alter discipline identity, or move classes between their reference attributes.
